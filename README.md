# SNP Heuristic: распределение дефицита

Распределяет доступный объём одной позиции в одном периоде между заявками. Правило: жёсткий приоритет между уровнями, пропорционально спросу внутри уровня, с учётом `min_lot` и кратности.

## Запуск

Нужен Python 3.10+. Для расчёта сторонние зависимости не нужны.

```
python3 main.py
```

На Windows: `python main.py` (или `py main.py`).

Команда считывает `data/supply.csv` и `data/requests.csv` и печатает по каждому кейсу, сколько получила каждая заявка и сколько осталось нераспределённым. Причины решений (карантин, перегруз, исключение по `min_lot`) печатаются перед таблицей кейса. Другую папку с данными можно передать аргументом: `python3 main.py path/to/data`.

## Тесты

```
python3 -m pip install -r requirements.txt
python3 -m pytest -q
```

## Структура

| Файл | Что внутри |
|---|---|
| `allocator.py` | Алгоритм: `allocate(available_qty, requests) -> dict[str, int]` и вспомогательные функции |
| `main.py` | Точка входа: чтение CSV, вызов `allocate`, вывод |
| `test_allocator.py` | Тесты: 7 кейсов из CSV и 4 собственных |
| `REPORT.md` | Отчёт: журнал решений, проблемы данных, вопросы аналитику, границы применимости, масштаб, многопериодность |
